# 09 运行配置与验证

本主题说明 release 的文件结构、连接方式、角色状态与验证边界。协议字段和静态调用链见01–08；安装、构建和工具准备见 [运行依赖](../../docs/运行依赖.md) 与 [构建与验证](../../docs/构建与验证.md)。

## 文件结构

以下路径均相对仓库根目录：

| 组件 | 路径 |
|---|---|
| 启动入口 | `start_nanaimo_launcher.bat` |
| 启动器 | `gui_launcher/nanaimo_launcher.ps1` |
| 客户端连接器 | `gui_launcher/client_connect.ps1` |
| 协议适配器 | `adapter/nanaimo_adapter.exe` |
| 适配器源入口 | `adapter/nanaimo_adapter.c` |
| 源码组件 | `release/components/<功能名>/` |
| 源码依赖清单 | `manifest/source_closure.json` |
| 运行文件清单 | `manifest/open_release_manifest.json` |

源码依赖清单记录递归 include 闭包及构建输出约定；运行文件清单记录文件大小与 SHA-256。文件身份检查不等于协议语义或客户端显示效果验证。

## 连接与角色资料

启动器使用 Network 模式连接 `127.0.0.1`；适配器监听地址为 loopback。登录、资料注册、游戏入口及游戏会话是不同连接，字段含义依连接和客户端状态区分，见 [协议分帧与连接](01-协议分帧与连接.md)。

进入游戏的流程包括保存所选角色资料和库存、加载本地适配器、等待监听、注册角色资料，再启动客户端。Standalone 构造器与 Network 构造器的协议差异见 [登录村庄与角色](02-登录村庄与角色.md)，不应混用字段布局。

## 持久化与状态载体

- 等级和经验使用按角色保存的进阶记录。配置参数 `level` 仅初始化缺失记录；已有角色使用持久化账本。
- C355 村庄资料、CF71 房间资料及 CF88 结算取自相应角色的等级／经验状态；资料载体见 [角色资料与背包](03-角色资料与背包.md)，奖励和结算字段见 [拾取结算与奖励](07-拾取结算与奖励.md)。
- HP/MP、攻击／防御策略、选中宠物及装备属性具有各自的载体与计算规则，不从等级值直接推导。
- 持久化文件名、数据格式版本和协议标识属于实现接口。内存中的已加载状态与磁盘文件不是自动同步关系。

## 证据与实现边界

静态分析用于确定函数调用、字段偏移及读取边界；适配器构造验证用于检查报文字节、顺序和状态门控；客户端运行观察用于说明特定输入下的实际行为。三类证据不能互相替代。

本地适配器中的数值策略不等同于原始适配器算法。SSTG、SMMO、PON 与道路资源的选择规则见05、06、08；同家族资源回退属于兼容策略，不等于恢复了缺失的原始资源。
