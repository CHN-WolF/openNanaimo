# 修道僧四村对白安装／程序位点

本页保留配套安装所需的程序位点信息；业务接入策略见[DIY专题](../../../业务/DIY/索引.md)。

## 二进制位点

所有位点先校验精确输入身份，再按配方写入目标字节。配方登记原值、当前值与支持的历史迁移值，重复应用保持幂等。下表完整列出本方案的位点和代码窗口，其中「配方分组」列为 `managed-host/Resources/client-compatibility.json` 中该位点所属的分组：`dungeon-state` 的两项只在安装命令给出 `--dungeon-state` 时应用，仅加 `--monk-dialogue` 不会安装。VA表示PE虚拟地址，长度单位为字节；写入文件偏移由PE节表映射，不能将VA直接用作文件偏移。

| VA／长度 | 配方分组 | 功能 |
|---|---|---|
| `0x72F265`／5 | `dungeon-state` | 本地选关调用，目标`E85641FBFF`。 |
| `0x6E33C0`／64 | `dungeon-state` | hd0、入口8～11映射episode24～27及dg0，保留寄存器、flags和ret4；入口上界立即数位于`0x6E33E2`，当前值03。 |
| `0x6E3800`／8,192 | `monk-dialogue` | 对白控制器、虚表、来源状态、四村表、GBK分页文案。 |
| `0x527CCD`／5 | `monk-dialogue` | 村庄点击及对白更新。 |
| `0x52A751`／5 | `monk-dialogue` | 原生hover后设置NPC光标及返城对白。 |
| `0x72F20D`／5 | `monk-dialogue` | 来源匹配后使用章节100初始化。 |
| `0x53CE10`／9 | `monk-dialogue` | 按冻结来源恢复本人角色坐标。 |
| `0x6E5800`／5,632 | `monk-dialogue` | 挑战UI与局部兼容代码。 |
| `0x737C49`／5 | `monk-dialogue` | 挑战创建页更新分支。 |
| `0x737DBE`／5 | `monk-dialogue` | 挑战概览背景分支。 |
| `0x737DED`／5 | `monk-dialogue` | 挑战通关／难度图标分支。 |
| `0x5278F1`／5 | `monk-dialogue` | 村庄最终UI阶段绘制对白，随后绘制光标。 |
| `0x764C96`／5 | `monk-dialogue` | 结果页中文关卡名。 |
| `0x737DAD`／5 | `monk-dialogue` | 创建页原生`call 0x411379`。 |
| `0x738A00`／8,192 | `monk-dialogue` | 返城对白、立绘、准备房名称及结果控件代码。 |
| `0x6F749D`／5 | `monk-dialogue` | 开战冻结当前挑战身份。 |
| `0x6FA2CF`／5 | `monk-dialogue` | 记录本人当前挑战的结算评价。 |
| `0x762F09`／7 | `monk-dialogue` | 原生结算更新，目标`8B55EC837A3C01`。 |
| `0x70F769`／6 | `monk-dialogue` | 准备房中间地宫／阶段编号。 |
| `0x70F750`／8 | `monk-dialogue` | 准备房左上角关卡名指针。 |
| `0x70FA22`／8 | `monk-dialogue` | 准备房BOSS资料指针。 |
| `0x762F74`／7 | `monk-dialogue` | 结果输入限定同关重试／回城。 |
| `0x76523A`／6 | `monk-dialogue` | 绘制对应结果控件。 |

对白虚表位于`0x6E4000`、来源状态`0x6E4040`、四村表`0x6E4100`、GBK正文`0x6E4800`；立绘初始化为`0x739080`。窗口回收使用状态1／2，结果评价使用0失败、1～5通关。具体字段定义由两个DIY主题维护。
