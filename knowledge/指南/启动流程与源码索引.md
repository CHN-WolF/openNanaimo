# GUI 启动链、知识库与源码阅读索引

本文按GUI入口、本地／社交Network启动、资料保存、完整adapter、地宫桥接和客户端连接顺序介绍源码。开发构建使用Python、TinyCC和.NET SDK；发布启动器使用内嵌托管工具，自包含运行包可直接在Windows运行。基础Nanaimo客户端由使用者合法提供，依赖见[运行依赖](运行依赖.md)。

<!-- FUSION END df-08-001 -->

## 启动与源码阅读入口

1. 运行`start_nanaimo_launcher.bat`，在GUI中选择已有档案或纯新手账户，显式保存角色、称号和库存配置。
2. 本地模式先使用“仅启动适配器”，再选择“进入Nanaimo”；社交模式先启动绑定指定局域网IPv4的适配器，再按P1／P2／P3参与。保存、停止、注册、副本准备与启动的完整流程保留在下文“GUI本地与社交动作”。
3. 构建与自检命令见[构建与验证](构建与验证.md)；兼容准备及回退见[客户端兼容操作导航](完整适配器与客户端兼容说明.md)。

源码调用图、Windows入口、托管／原生构成、端口、桥接状态与GUI资源由[适配器架构](../工程/适配器架构.md)统一维护；[启动运行](../工程/启动运行.md#df-08-005)维护Network模式、纯新手及持久化边界；[构建发布](../工程/构建发布.md#df-08-012)维护构建文件身份；[验证状态](../工程/验证状态.md#df-08-014)保留原验证范围。下文阅读顺序中的兼容说明路径是操作入口，具体事实从该入口转到上述工程主题。

## 4. GUI 本地与社交动作

### 保存配置

校验并显式保存profile、称号和库存；服务与客户端启动使用各自独立入口。库存工具的增量事务、按变更备份及离线保护由知识库[工程／启动运行](../工程/启动运行.md#kb-09-017-1)维护。

### 仅启动适配器

```text
adapterBtn
  -> 已运行：Stop-LocalAdapter
       -> 写 adapter_data/stop.request
       -> 等待 Nanaimo.Adapter.exe 正常退出
       -> 必要时终止残留桥接进程
  -> 未运行：确认编辑状态与已保存配置一致 -> Start-LocalAdapter
```

### 本地模式：进入 Nanaimo

```text
clientBtn
  -> 固定解析为 Network / 127.0.0.1
  -> Assert-LocalAdapterRunning
  -> 解析所选账号档案，或生成纯新手隔离 profile
  -> Test-ClientBinary
       -> 仅确认 game.exe 文件存在
       -> 不检查脱壳实现的大小／哈希
       -> 不检查本地派生的 pack、SSTG 或 PON
  -> Install-LaunchModeConfig
  -> Ensure-ClientCompatibility
  -> Register-ClientProfile / Register-PureNewPlayer 127.0.0.1:11999
  -> 启动一个新的 game.exe
```

该入口复用已运行且绑定`127.0.0.1`的Network adapter和已保存档案，保持现有客户端及服务生命周期，支持本机多开。准备客户端前检查适配器运行状态，资料注册校验端口可用性。角色数值和库存编辑须先显式保存，适配器按钮负责启动／停止；纯新手账户通过会话级门控按真实进度开放地宫。

`Start-LocalAdapter` 不使用固定睡眠后直接放行，而是在10秒窗口内轮询绑定地址上的 `11005/11999/12050`，三个入口全部可连接且归属新进程才返回。

### 社交模式启动与参与

```text
socialAdapterBtn
  -> Normalize-NetworkIPv4
  -> 校验已保存的ProfileIni，再执行服务切换
  -> Stop-LocalAdapter
  -> Start-LocalAdapter <LAN IPv4>
  -> 写 adapter_ip.txt 并显示地址／PID

P1/P2/P3
  -> Ensure-ClientCompatibility（符合条件时复用会话准备结果）
  -> start_social_client.ps1（每次参与仅调用一次）
       -> 在槽位锁内准备副本、独立网络配置／工作目录及运行保护
       -> 副本改写槽位互斥体及已登记的图像资源共享读取位点
       -> BeforeLaunch：Register-SocialAccount -> TCP 11999
       -> Start-Process 并等待非零窗口句柄
```

adapter 的注册队列按来源 IPv4 隔离；同机 P1／P2／P3 依按钮顺序消费，其他机器使用各自来源队列。用户名是数据库账户身份；新账号进入纯新手建角，已有角色沿用持久化档案。各槽位的客户端副本位于源客户端旁，工作目录、网络选项、运行时缓存和用户目录独立。准备、复用、清理及回滚步骤见《完整适配器与客户端兼容说明》的社交多开副本章节。
