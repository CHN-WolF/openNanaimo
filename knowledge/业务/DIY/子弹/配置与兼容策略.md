# 业务／DIY／子弹／配置与兼容策略

## 范围与适用条件

本页维护 DIY 子弹的 GUI 目录与别名映射、客户端本地配置及反向兼容边界。接入顺序与资源依赖见[接入与资源链](接入与资源链.md)，验证层次与伤害归属见[分层验证](验证与伤害边界.md)。目录数量是固定快照，不代表逐项实机可用。

## 目录与预览接入

| 文件 | 维护字段或身份 | 实际消费者 |
|---|---|---|
| [`projectiles.json``gui_launcher/data/projectiles.json` | `file`、`owner`、`row_count`、`primary_eff`、`style_label`、`monster_label`、`effect_images`、`attack_values`；原资源项还记录大小与 SHA-256 | GUI 列表、搜索、详情、配置资源存在性检查；不是完整资源安装清单 |
| [`projectile_aliases.json``gui_launcher/data/projectile_aliases.json` | 七个原 PON 名到独立别名的映射 | GUI 展示与保存转换、安装器派生；运行时白名单另在桥接源码中审核 |
| [`projectile_frames.json``gui_launcher/data/previews/projectile_frames.json` | 原资源代表图、图集坐标、可用状态、GIF 名与帧数 | GUI 原资源预览；当前有 2,995 项 |
| `basketball_spin.gif` | 独立 16 帧篮球预览 | GUI 对篮球的专门分支 |

新资源要经 GUI 选择，至少需要目录项与可用的客户端 PON。原资源预览与篮球预览走不同分支；没有预览的项可以显示“无可用代表图”，不能以预览缺失推断资源不存在。目录项目当前为 2,996 项（原资源 2,995 项、篮球 1 项）；这是固定快照数量，扩展后须同步更新相应目录闭包测试。

## 客户端本地配置

| 步骤 | 当前实现行为 |
|---|---|
| 选择 | 仅更新 GUI 当前选择；双击或“选中列表子弹”后仍需保存 |
| 保存 | 退出目标客户端后写独立 `nanaimo_projectile.ini`；不改角色存档，不在保存按钮内安装 |
| 准备客户端 | 启动器读取根目录配置；`enabled=1` 时执行可选安装器 |
| 首次预载 | 桥接读取 `game.exe` 同目录的 INI，检查所选 PON 存在并预载 |
| 运行 | 有效战斗对象、启用、预载成功且已经满足松键门槛后，按 V 以 90 ms 节流发射；重建对象后先松 V |
| 更改 | 配置与资源升级在退出客户端后完成，下次启动生效 |

配置节名 `[Flamethrower]`、字段校验、GUI 与客户端直接读取时的反向缺省差异见[配置生命周期](../../../工程/子弹DIY兼容/配置生命周期.md)。

## 反向兼容

`reverse_direction` 影响所有 DIY 发射的出生方向计算与 side 参数；专用行几何／绘制反射只覆盖篮球与七个精确别名。对其他资源，开关仍改变发射上下文，但行模拟和绘制继续走原生处理，不能承诺完整反向轨迹。

| 资源组 | 别名 | 反射门控行数 |
|---|---|---|
| 篮球 | `nanaimo_basketball.pon` | 3 |
| ep02 的 `mis_ep02_hd_bbm_08_00..05.pon` | `\u0071\u0071fxd_cmp_005_0024.pon` 至 `\u0071\u0071fxd_cmp_005_0029.pon`，按后缀一一对应 | 每项 5 |
| ep09 的 `mis_ep09_bbm_02.pon` | `\u0071\u0071fxd_mov_009_0000.pon` | 9 |

别名沿用映射 JSON 的 Unicode 转义表示；运行时应使用解码后的文件名。

门控还要求每行 EFF 非空、trail／transition／私有标记为零；任一行不满足时不写入整组标记。六个 ep02 项额外以 row0 为中心进行一次初始几何反射；绘制反射使用 48 字节的 12 个浮点轨道副本。完整层次与字段偏移见[篮球资源与反向范围](../../../工程/子弹DIY兼容/篮球资源.md)。

代码证据：

- [`projectile_browser.ps1``gui_launcher/projectile_browser.ps1`：目录、别名与保存分支。
- [`projectile_diy_asm.py``scripts/projectile_diy_asm.py`：`fire_bridge`、`diy_spawn`、`mark`。
- [`generate_projectile_diy_recipe.py``scripts/generate_projectile_diy_recipe.py`：生成固定地址配方。

修改 JSON 映射不会自动修改机器码白名单，扩展须重新构建并核验配方。
