# DIY／任务／目录与对白

## 范围与边界

适用于使用者自备韩服资源向当前 CN 项目派生章节数据。源目录、章节次序与 KR 地址由[韩服章节剧情](../../角色/任务/韩服章节剧情.md)唯一维护；CN 槽位和目标索引由[窗口协议与客户端消费](../../角色/任务/窗口协议与客户端消费.md)维护。目录工具与客户端剧情分别采用独立验收状态。

## 编号与格式

任务 ID、目标 ID、QS 文本 ID、SCRIPT UID、NPC UID、地图页面和战斗 episode 属于不同命名空间。相同整数不能代替引用转换；尤其不能把 SCRIPT10000 写成任务说明 QS10000。

`scripts/prepare_story_catalog.py` 独立解析 CN／KR QT，完整消费可变目标数组、平行值数组、奖励三元组、KR 后继／附加字段和尾部 NPC 绑定。附加三元组包含纹理路径、名字等混合类型。目标原始字段、所有动作属性、空的 `dungeon/level` 属性和 `CONDITION goto` 均保留；未确定字段保留原始定义。

工具校验源输入 SHA-256、唯一 ID、完整尾部、目标顺序、章节后继、脚本引用、QS 引用与覆盖计数。派生产物为 `catalog.json`、`localization-review.json`、`manifest.json`，只在新建隔离目录写出，`verify` 从同一输入重新生成并逐字节比较。工具输出范围限定于离线目录。

## 复用既有实现

四个修道僧挑战仍由原目录、NPC 控制器和成功账本维护，各对象沿用唯一所有者：

| 对象 | 复用方式 |
|---|---|
| 原 SCRIPT10032..10035 | 对照现有派生 SCRIPT24000..24003；逐动作保留对白、条件、失败／成功 COMPLETE，仅使用既有 D_START 身份转换 |
| NPC62..65 | 复用[场景与输入](../NPC/索引.md)与既有NPC身份 |
| QS6000..6011 | 中文唯一来源为 `manifest/monk_localization.json`，从新增翻译审核清单排除，以 `reused_monk` 记录所有者及映射 |
| 战斗与返回对白 | 复用 `hd0/ep24..27/dg0/st0` 及[结算与进度](../地宫/修道僧结算与进度.md)及其准备房、重试和返城授权 |
| 通关资格 | `CharacterMonkChallenges.ClearMask`维护永久独立挑战资格；章节须另核对[当前任务后的新结算](../../角色/任务/章节剧情移植进展.md#修道僧目标与任务槽)，不能复用历史位跳步 |

当前 CN 修道僧窗口的正文由 `monk_dialogue_compat` 从本地化所有者生成并嵌入，松散 QS 的同 ID 文本不必等同于该窗口实际正文。工具分别记录 `installed_qs_matches_owner` 与脚本结构匹配；发现松散 QS 差异不覆盖、不重翻译，也不据此宣布窗口错误。旧安装是否与当前程序配方一致必须独立检查，资源核验不能替代实机。

## 本地化与发布资格

扣除复用的12条修道僧对白，待审 QS 为139条：107条章节对白、16条章节说明和16条奖励文本；另有16个标题和52个目标名。审核模板默认空译文、`approved=false`，不把工作译名变成已审中文。

中文必须严格编码为 GBK，拒绝 `#`、NUL 和非法格式化指令；保持 `%s` 等参数的种类／数量和 `^&` 的显式断行结构。客户端名称长度按编码后字节和 NUL 空间检查。候选分页采用每行最多48个GBK字节、每页最多4行；分页保留说话者、动作属性、动作内页索引和动作末页标记，不把一条长SPEECH当成单页，也不把每页当成一次COMPLETE。该分页规则的验证层级为主机构造，客户端状态为`runtime_acceptance=false`。

`manifest/story_localization.json`是16章候选译文唯一所有者：139条QS、16标题、52目标名均保留原文和`approved=false`。`prepare_story_port.py`派生`release/components/story_chapters`，包含完整32段正文动作及4个修道僧来源动作／既有身份引用，后者以12个QS编号引用既有中文所有者。源码内嵌该包，73链首次授予采用独立启用契约。

术语表`manifest/story_terms.json`与`audit_story_localization.py`逐项核对实际CNQS／GS、卡片目录及既有修道僧本地化所有者，并拦截候选异名和韩文残留。已核对词条包括QS1000“尼莫”、QS506“恰恰”、QS552“伊露卡”、QS533“阿郁塔”、QS1012“小云云”、QS1013“卡片册／魔法钥匙／特殊卡片”、GS8030“黄金粉末”以及章节场景名。CN `ddakg._D4`卡片20／37／59／73／111的合成说明分别支持“蓄能药水40／紫色兔子／小斑点狗／耍宝小猕猴／帅帅的哈士奇”；中文译名按CN词条统一；未闭合的人物别名及其他宠物／奖励逐ID对应保留待核对，术语审计通过不等于译文全部审核。

`manifest/story_portrait_resources.json`覆盖18名正文角色、37项EFF／IM3依赖，包括第一村新增NPC53..56。`prepare_story_portraits.py`核对动作NPC／expression集合、源SHA-256、图片头及EFF依赖，在独立目录生成候选。目标存在同名异字节文件即拒绝，交付对象为隔离候选目录，NPC场景绑定、安装事务与立绘生命周期按生产启用契约验证。

输出状态为`activation_allowed=false`。生产启用条件包括CN通用执行器、确认协议、场景时机、type40判定、首次授予、奖励映射、NPC立绘、本地化、安装恢复和第一章客户端验收。原始奖励字段用于目录审核，实际奖励类型与期限由独立事务契约决定。
