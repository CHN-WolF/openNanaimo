### 扩充券action映射与到期字段

- **城镇食物**：`C43D/16` 对应 `C43E/20 -> C43F/12`。C43F 的 WORD+8/+10 表示本次实际 HP/MP 恢复增量；资源目录提供效果值，DB 消费与恢复在同一事务提交，非200结果保持库存与资源状态。

- **扩充券**：`C480/12` WORD+8 为协议 action，WORD+10 为点击实例 实例身份。
- 资源 raw type `0,1,2,3,4,5,6` 映射协议 action `0,3,2,1,4,5,6`；DB 以 raw1 存 PET、raw3 存 Interior。
- 事务使用被点击的 物品类别44 券。
- `C481/20` 使用 BYTE+8=result、BYTE+10=action、BYTE+11=实例身份、DWORD+12=exact code、DWORD+16=expiry；结果0扣除确切券，结果1保留库存。
- 重放缓存同时比较 control 与完整 payload。

- **扩充恢复**：C3CC BYTE+9=4、expiry DWORD+684；C430 BYTE+9=6、expiry+684；普通背包 C40A 使用 BYTE+10=6、expiry+1024，BYTE+9 为新增提示；C44C 使用 BYTE+9=4、expiry+2028。
- PET 代码保持在其独立字段，PET 仅在到期值可解码且晚于当前时间时发布扩充模式，过期值保留在存档，运行时保持续用入口可用；PET 到期值使用既定尾部；C44C BYTE+11 与行 WORD+8 共同决定选中状态，无选中使用 255。

### 库存即时刷新与启动器期限控制

- 刷新：普通道具、喇叭、类别47钥匙、复活礼包及背包扩容操作完成后，立即在当前页面发布更新后的库存。
- 幂等：重复提交复用已结算结果，保持只扣除一次。
- 验证范围（静态／本地）：背包扩容覆盖全部受支持类型0～6。
- 版本锚点：该行为随2026年9月27日部署的适配器生效（不构成原客户端可见行为验收）。
