### 200级经验状态与内部版本边界

- 人物内部权威字段为真实64位累计、等级和CurveVersion3；读取时校验曲线一致性。
- `NativeDungeonState`采用库存结构版本4、payload5704/full5712，联合校验版本、长度和曲线。
- CurveVersion为3，F10B为v3、payload48/full56。
- 精确布局见`knowledge/基础/桥接布局.md`；64位累计使用独立尾部字段，宠物经验沿用既有契约。
- 运行产物身份归[200级成套发布与数据版本](持久化与离线迁移.md#kb-09-007-2)。

- C355、CF71、C57C、CF88以及任务C59A、竞技/娱乐室结果统一投影为级内DWORD。
- CF88每条记录按本人状态投影，added是独立真实奖励；不得把级内当前值覆盖数据库。
- 完整构造清单见[对外经验载体扫描及落点](#df-05-003)，迁移流程见[曲线迁移契约](持久化与离线迁移.md#df-05-005)。
- 200级仍有真实的最后一级经验条，完整区间／停止奖励策略归[玩家累计经验范围与原生曲线边界](曲线与经验奖励.md#kb-07-004)；CF71继承lower0、跨级动画/页面缓存/重登仍待原客户端实测；发布与验收状态由[验证状态](../../../工程/验证状态.md)维护。

本主题按资料载体和交易机制维护当前协议、适配器策略、持久化边界与验证范围。

### 经验载体元组与进阶记录读取

- 玩家等级／经验使用按角色持久化的进阶记录。
- 原生配置参数 `level` 仅初始化缺失的 `level_progress_state_v1_<name-hex>.dat` 数据库记录，已有进度不会因登录或资料应用而重置。
- 登录／房间资料应用时重新加载该记录，击杀及CF88结算各自提交后更新当前连接等级（策略见[玩家累计经验范围与原生曲线边界](曲线与经验奖励.md#kb-07-004)）。
- C355／CF71构造在校验和计算前统一经验载体，沿用既有发送边界、进阶记录、阈值曲线和结算升级标志。
- HP/MP保持独立的u16资源，并叠加选中宠物宝石增益；适配器实际升级按[人物成长策略](人物成长与同步.md#kb-04-005-1)增加基础上限，客户端消费适配器提交的成长值。
- 攻击／防御策略见[人物攻击与防御](../../地宫/伤害与目标/攻击与防御.md#kb-04-005-2)，选中宠物／装备属性保持独立。

- 经验记录不能以接收方套接字或截断的显示名称为键。
- 静态调用链见[玩家经验载体和HUD静态调用链闭合](#kb-08-016)；历史本地自测覆盖等级1..99序列化、双资料隔离、村庄／下一阶段／重新登录连续性，以及已确认击杀／终局事务触发的经验同步；该历史范围不等于当前等级上限。

- 历史上，99级上限属于适配器策略，不能解释为客户端显示字段只有两位；当时记录的“99级规则未变、尚无三位等级运行验收”仅描述旧版本状态。
- 当前人物上限为200级，托管`CharacterProgression.MaximumLevel`与原生`PROGRESSION_MAX_LEVEL`均为200。
- 城镇压缩等级与主要BYTE载体的不同位宽、CN/KR差异及扩展范围由[玩家等级上限、三位显示与入口资格](客户端版本与显示.md#kb-08-020-1)统一维护；200级的原客户端运行验收范围以[验证状态](../../../工程/验证状态.md)为准，不能由旧1..99构造测试推断。

- 原生进阶记录通过数据库中的`.new`/`.bak`键事务替换。
- 历史说明记录过`version=1`、`level`和累计`exp_total`，以及曲线不一致时回退到该等级下限种子的旧规则；这不再是当前读取规则。
- 当前记录名仍保留`level_progress_state_v1_<name-hex>.dat`，载荷实际写入`version=3`、`curve_version=3`、`level`和64位累计`exp_total`，校验版本、曲线、1..200等级及累计经验对应等级。
- 主记录存在但无效时立即拒绝启动，不尝试以备份或配置种子覆盖；主记录缺失时可恢复有效备份，备份存在但无效时拒绝并要求离线迁移；仅当主记录和备份均不存在时，才按配置等级的下限初始化种子。
- 角色键使用配置名称字节的大写十六进制编码，与其他按角色保存的记录一致。
- 源码依据为`release/components/dungeon_progression/progression_runtime.inc`的`progression_progression_parse_path`、`progression_progression_save_name`和`progression_progression_read_name`；数值策略和CF88字段见[玩家累计经验范围与原生曲线边界](曲线与经验奖励.md#kb-07-004)。

### 玩家经验载体和HUD静态调用链闭合

- 战斗分数、临时经验与结算入账分层处理：D00E/48的 `6EC8B7..6EC8D3` 和D012/60或64的 `6ED9B5..6ED9DA` 读取DWORD+8/+0xC/+0x10三槽分数，经 `403323 → 748990` 按row+0x288槽写row+0x28C（stride0x2C）并刷新数字；D010/36在 `6EF06B..6EF094` 读DWORD+0xC，经 `41CCD8 → 66E740` 的actor+0x7A4C槽进入相同写入链。
- 适配器保持这些实时分数字段原值。

- `40876F → 748C90` 排序显示后在 `748ED0` 选择本地槽；等级<80时 `748EF9..748F28` 乘double 0.25（C79948），经 `401005 → 74C190` 写global+FD0，等级≥80在748F37写零。
- 74C190仅由thunk401005引用，该thunk的调用点为748F28和748F37；`409133 → A76240` 按selector0/1/2返回原值／一半／零，`8E1620` 在8E1AF4/8E1B19把临时值加到 `4061CC → 834000` 的global+FCC已提交经验后钳到下级阈值。
- 兼容项在74C19A将setter输入清零，完整25字节门禁及精确三字节修改见客户端兼容说明1.2.1；分数、CF88奖励和已提交经验保持原值。

- EXP字段闭合依据307条解析器／HUD指令。
- 0x6EBAC0完整分派器没有可用的反编译结果，相关case由IDA反汇编闭合，不能将其描述为完整反编译。
- 协议策略与数值来源见[200级经验状态与内部版本边界](#kb-03-001)、[玩家累计经验范围与原生曲线边界](曲线与经验奖励.md#kb-07-004)。

- C354 构造函数0x54DCD0（thunk0x41F9A6），状态1发送者0x52ACB0/0x52ACCD ->0xADA3E0（socket0）；C355 角色分派器0x531DA3 ->0x41646E ->0x530C90，全长728（最后WORD+0x2D6）。

- C355+0x80/+0x84副本前提部分单独保留，不包含EXP。

- CF70/12构造函数0x708400通过thunk0x404165实现；controller0x6E94C0在0x6E9506处构建，将controller+0x7C复制到request+8，发送操作在0x6E951B处，指向0x40A821/0x6E90C0 ->0xADA3E0（控制器套接字索引+0x78）。

- CF71 是0x6EBAC0中的 case53105。
- 本地 UID 分支0x6F4FD0..0x6F4FF5使用与 C355/CF88 相同的设置函数，将 DWORD+0x40写入 next、DWORD+0x44写入 当前值，不写 lower。

### 累计经验数值范围与float32精度

- 共享lower/current/next为Character+FC8/FCC/FD4的完整DWORD，setter `4D7BC0/4D7BE0/4D7C10`直接赋值。
- FC8/FCC/FD0/FD4共有14处显式字段访问；`A6DEB0`在`A6E5CE/A6E5DE/A6E5EE/A6E5FE`依次清零四字段。
- 阈值消费路径接受资料记录中的数值，人物曲线由[玩家累计经验范围与原生曲线边界](曲线与经验奖励.md#kb-07-004)统一定义。

- 主HUD `8E1BFF..8E1C0B`用无符号`jnb`钳当前值至next；`8E1C87..8E1CBF`先做DWORD减法，为结果补高DWORD=0，再以qword `fild`转浮点并相除。
- CF88 `6F9D88..6F9E3A`同样先减、补零、`fild`、除法后乘double100。
- 因此上述路径支持u32阈值。
- `82F64C..82F6AE`同样先取无符号差再转浮点；`A23789..A237EB`检查next-lower非零后以无符号`div`整除，再乘100，其显示精度按整数比值计算。

- 经验UI `A21CA0 → 416301 → A22120`在`A22F33/A22F5A/A22F81`分别读current/lower/next，在`A22F4E/A22F75/A22F9C`分别以`fstp m32real`保存后，于`A22FAC..A22FC6`相减／相除。
- 三处机器码为`D99D98FDFFFF/D99DA0FDFFFF/D99DA8FDFFFF`，D9 /3编码确定32位浮点精度。
- 零检查针对next本身，曲线另须保证舍入后的分母大于零。

- 最近舍入、浮点异常屏蔽条件下，`(lower,current,next)=(0,2147483648,4294967295)`的差值比例约0.5，`(4000000000,4100000000,4294967295)`约0.33902064；三值先存float32的路径中，`(16777216,16777216,16777217)`和`(4294967294,4294967294,4294967295)`因分母舍入为0得到NaN。
- 这些结论限定为数值计算边界；曲线及满级显示区间按[人物经验曲线](曲线与经验奖励.md#kb-07-004)的规则校验。

- C355的`530E57/530E69/530E7B`按+0x28/+0x30/+0x2C读取DWORD并直接交setter；C57C `6EB6F0`同类写入。
- CF88的`6F9D88/6F9DB4`分别从记录current/next减lower，补高DWORD零后转浮点。
