### 主线新手引导与配置装备隔离

- 所有已建角色从持久化 `Appearance` 恢复登录外观；未完成教程时，仅对 `271A` 的 D6/D7 执行教程安全投影。
- `Characters.PureNewProfile` 与建角同事务保存，每次登录和频道刷新恢复。
- `C368`、`C36A` 与尼莫对话前后共享角色保存的外观，档案生命周期由账号和角色身份维护。

- 引导阶段 `C354` 返回 `C355/728`，携宠标志 `+0x0D=0`。
- 有效 `C353` 原子保存完成状态并返回 `C594/12`；后续 `C354` 按 `C355 -> C476 -> C44C` 初始化普通库存及宠物，首次 `C367/C368` 恢复全部保存装备。
- 非法身份、长度和重复完成事件沿用输入校验与幂等规则。

阶段门控由 适配器 实现。男女各4组装备状态、无角色入口、配置保留与完成后即时恢复已通过数据库及协议构造检查。静态边界见[主线引导 D6 与普通村庄加载差异](#kb-08-010)，发布产物与验证范围见[集成发布验证](验证范围.md#kb-09-020-12)。

### 纯新手档持续游玩与地宫前置

纯新手档在创建角色后保留玩家选定的基础外观槽位；教程阶段只暂时屏蔽特效和宠物槽，教程完成或重新进入村庄时恢复已保存的完整外观。纯新手档用户名由启动器单独保存，填写已有用户名即可继续对应角色；历史生成的纯新手账号也支持以其已有角色名找回，已有角色不会被重新创建或覆盖。

- 纯新手档始终按原始进度逐个开放地宫，只有前一地宫链完成后才允许进入下一地宫；该模式不允许开启“全部地宫进入权限”，运行值固定为 `unlock_all_dungeons=0`。
- 第五村继续保留既有进入兼容机制，但仍要求前置普通地宫全部满足。
- 常规角色档是否使用便捷开放策略属于独立配置，不改变纯新手档约束。

### 新手教程门控

主教程的进入判定已定位到适配器控制的登录字段：

```text
271A byte +0x0E
  -> sub_4E3830
  -> 角色信息对象 byte +3
C352 成功
  -> sub_4DFAA0 本地 phase5
sub_4DF1E0 phase5
  byte +3 == 0  -> 全局 state12（主教程）
  byte +3 != 0  -> 全局 state1 （跳过教程）
```

Network 模式使用角色资料参数 `skip_tutorial` 控制教程入口。跳过路径仍由请求驱动：C351 只收到 C352，随后客户端直接发出 C354；适配器返回 C355，重新应用角色资料门控，再发送 EA61 scene0。此路径不发送教程 EA61，也不合成 C353。

直接进入游戏的状态链为 `C351 → C352 → C354 → C355 → EA61(scene0) → C367/C368`，按角色与页面状态逐步完成初始化。

### 每个角色教程选项

角色资料参数：

```text

skip_tutorial=0|1

```

对于网络模式，此值在每次上传客户端角色资料时携带。显式的`1`写入271A `+0x0E=1`；显式的`0`写入零。遗留的上传角色资料中省略该键默认为零，而不是继承适配器范围内的跳过设置。该字段是适配器自定义策略，并非库存/账户持久性声明。

教程参数作用于角色初始化状态链，见[主线新手引导与配置装备隔离](#kb-02-002)；库存采用独立持久化规则。

### C355首次进入标记与村庄页面选择

- C355 处理函数 `sub_530C90` 在 `0x00530F69..0x00530F88` 读取 manager+`0x7B4` 的一次性门（getter `0x0054D470`；构造时 `0x00A6E3C4` 初始化为1），随后经 `0x0054D450` 清门，并通过 `0x00A75270` 把 manager+`0xD38` 的 `FirstVillageFlag` 置1。
- C355 完整帧 `+0x20/+0x21` 同时在 `0x00530F1A..0x00530F5E` 选择当前村庄／页面，发生在首个 C367 前。

### 主线引导 D6 与普通村庄加载差异

- `CGuideChar` 的 `sub_917D90` 在 `0x0091812A` 读取正确 D6 参数，却在 `0x0091811A` 传入标志0，经 `0x00918144 -> 0x00413A84 -> sub_4EE3A0 -> sub_4EDEA0` 进入普通图片分支。
- 普通村庄 `sub_4FE260` 的D6传入效果标志1。
- `.eff` 经图片加载器的 pack／cache 门后可能触发不支持扩展名分支；不能仅凭EXE中无 `a_ef` 字符串判定不支持该资源。

适配器采用[主线新手引导与配置装备隔离](#kb-02-002)定义的引导阶段外观投影，保留原生加载指令。引导阶段与普通村庄分别使用各自的资源加载路径，状态及外观恢复已纳入构造回归。
