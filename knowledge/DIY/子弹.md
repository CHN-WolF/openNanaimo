# 弹体 DIY 接入

本页整理仓库的可选子弹 DIY 与篮球范例，说明如何把已有资源选择与客户端行为做成独立、默认关闭、可恢复的功能。用户可见操作见[子弹 DIY 与篮球试玩](../指南/子弹DIY与篮球试玩.md)；精确字节和资源合同仍由[子弹 DIY 兼容事实页](../工程/子弹DIY兼容.md)维护。

## 范例做了什么

弹体浏览器提供原资源目录项与独立篮球选项。选项最终落到 PON、EFF、IM3 和别名清单；可选客户端功能负责 V 键连续发射和限定名称的反向处理。配置保存在 `nanaimo_projectile.ini`，与角色档案和适配器伤害规则分离，默认关闭。篮球示范了复用原轨迹参数、使用独立资源名和动画图像，而不覆盖原炮弹。

相关代码与数据：

| 职责 | 入口 |
|---|---|
| 浏览器与选择 | `gui_launcher/projectile_browser.ps1`、`gui_launcher/projectile_resources.cs` |
| 资源及来源别名 | `gui_launcher/data/projectiles.json`、`gui_launcher/data/projectile_aliases.json` |
| 篮球源图、帧描述与生成 | `scripts/assets/projectile/`、`scripts/generate_basketball_animation.py` |
| 客户端完整字节合同 | `manifest/projectile_diy_patch.json`、`scripts/generate_projectile_diy_recipe.py` |
| 安装、升级及回退 | `scripts/prepare_projectile_diy.ps1` |
| 隔离回归 | `scripts/test_projectile_diy.py`、启动器 `-SelfTestProjectile` |

## 接入步骤

1. **明确功能边界。** 确定是替换浏览用资源、增添独立弹体，还是改变客户端发射行为。角色发射器、宠物技能与适配器伤害归属不能因客户端外观补丁而隐式改变。
2. **登记资源谱系。** 指定原始资源、派生文件名、适用别名和保留字段；图片、效果、轨迹文件分别记录格式与摘要。未知同名文件必须报冲突，不应静默覆盖。
3. **把预览与运行资源对应起来。** 预览可以用 PNG/GIF，运行时消费的仍是目标客户端支持的 PON/EFF/IM3。动画帧数、方向、尺寸和轨迹参数应由生成脚本或清单可重现。
4. **隔离配置。** 使用独立配置项记录启用状态、资源选择和反向选项；写配置与修改客户端资源是不同动作。配置在预载或下一次客户端启动才生效时，应明确告知用户。
5. **接入客户端时先设门禁。** 为目标 PE、导入槽、地址映射、原始指令和资源文件身份建立完整合同；代码修改限定在有记录的位点。只对清单允许的弹体名称与对象形态执行变换，并保留原模拟数据。
6. **提供事务操作。** 支持只读预检、重复安装、已知旧版本升级、冲突拒绝和显式回退。保存被替换文件的内容寻址备份；提交顺序与失败逆序恢复应覆盖程序和资源。
7. **分层验收。** 检查资源解析与动画、位点／栈／对象门控、配置生命周期、升级／冲突／回退。游戏内运动、碰撞、死亡、切图和联机表现单独验收。

## 范例的复用边界

- 当前反向处理只针对清单列明的篮球与兼容副本；不要把个别弹体变换推广为全局旋转规则。
- 90 ms 节流、行对象门控、12 条绘制轨道副本以及 PE 地址都是该范例的当前实现参数，不是通用 SDK 接口；新增目标布局应重新调查并登记证据。
- 隔离测试证明被建模的指令和事务边界，不证明任意客户端版本、复杂运行轨迹或多人可见性。
- 精确站点、资源字节、兼容旧版和恢复命令只维护在[工程事实页](../工程/子弹DIY兼容.md)；用户安装步骤维护在[操作指南](../指南/子弹DIY与篮球试玩.md)。
