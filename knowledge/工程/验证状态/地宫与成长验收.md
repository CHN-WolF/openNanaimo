# 工程／验证状态／地宫与成长验收

返回[主题索引](索引.md)。

## 当前验证范围

当前发布身份由三份活动清单维护。本页区分适配器构造、事务、客户端指令与完整游玩验收，规则由对应业务主题维护。

<a id="地宫跨难度续关验证"></a>

### 地宫跨难度续关验证

客户端难度按0→1→2推进，持久成绩索引按1→2→0映射。挑战超级BOSS保持客户端难度，内部资源槽位按BOSS规则选择；完成超级BOSS后的升难度回到目标难度的地宫0／阶段0。结算失败和最高难度使用所属结果动作资格。规则归[跨难度续关](../../业务/地宫/关卡与房间/续关授权与加载门控.md#跨难度续关)。

## 结算库存与挑战入口验证

结算食物完成库存确认和实际HP／MP恢复，换宠完成库存及角色资源同步；两者保留结算冻结和续关资格。覆盖三档难度下单人及双人的挑战、BOSS同关重试、资源槽位、全员加载屏障，以及吃药、换宠与挑战的连续操作。库存规则归[结算页食物与队列边界](../../业务/库存/消耗品/食物与通用使用.md#结算页食物与队列边界)。

组队结算校验房主先后切阶段、队员挑战／升难度及重复响应。临时过渡响应带入正确客户端难度，房主与队员分别保留各自结算授权。

### 客户端难度顺序与永久加载

客户端application难度与持久索引分别验证；`hd0/ep2或3/application1`使用`middledg`按钮文案，其他章节按所属分支选用文案。定向回归覆盖ep2从客户端难度1到2，以及同一房间连续完成三档难度的完整加载周期。存档投影、CF99加载分支、死亡重试和最高难度边界分别检查。

当前验证层级为客户端指令及适配器构造，完整客户端连续游玩状态为`runtime_acceptance=false`。

<a id="哈希奥终章奖励验证"></a>

### 哈希奥终章奖励验证

覆盖首次及重复领取、会话归属、教程／尼莫前置、11与12枚勋章、旧版待发记录、84行道具及255张卡片边界、钱包溢出、中途发奖失败回滚、严格配置、数据库重开及请求驱动刷新；公寓故事引导覆盖72项故事／有效资源检查。奖品内容按项目策略维护。

验证层级为客户端指令、适配器构造与SQLite事务。完整客户端的哈希奥对话、成功与满背包提示、礼包使用及重新登录采用独立验收状态，`runtime_acceptance=false`。

<a id="共享资源卡池资格"></a>

### 共享资源卡池资格

`ep01_dg00_mb_36_1_00.mmo`行0主体具有所属卡池资格，行1～16按独立小对象规则结算。规则归[卡池与奖励资格](../../业务/地宫/掉落/卡池与奖励资格.md#普通终结资格)。

检查范围包含两名玩家、三档难度、九槽的320次小对象与20次主体终结，以及HP归零／回收、Hans路径、非致死、重复终结、领取幂等和新周期资格；两份C箭资源覆盖728次箭终结与56次主体终结，另覆盖五种活动卡箱。七项CSV／概率检查覆盖27%装备加成、幸运草120%／200%、溢出封顶、精确资源行边界与随机数消费；普通／运行时目标生命周期和库存桥接分别验证。

验证层级为资源目录、适配器构造及生命周期，完整客户端游玩状态为`runtime_acceptance=false`。
