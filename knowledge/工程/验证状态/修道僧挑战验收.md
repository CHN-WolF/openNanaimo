## 修道僧独立挑战

当前发布包含四村NPC对白入口及`hd0/ep24..27/dg0/st0`四关挑战，实现状态为`village-dialogue-bound`。源码、运行文件和关键发布文件分别由`manifest/source_closure.json`、`adapter_runtime/adapter_manifest.json`、`manifest/open_release_manifest.json`登记。

## 当前功能

| 主题 | 当前结论 |
|---|---|
| NPC位置与绘制 | 四村出口固定位置，48×96命中范围，场景第1层按脚底Y排序，身体／阴影／名牌采用配套偏移。 |
| 名牌 | 46×24中心锚点，13号中文、白色字面、1像素深棕描边、2像素行距、原版英文像素字形。 |
| 点击与对白 | 手形1，左键按下沿，底部四行分页，Enter／按钮推进，Escape关闭，窗口按打开／关闭状态回收。 |
| 立绘与层次 | 四村NPC62～65立绘，逐帧推进动画；对白及立绘位于聊天／HUD之后、光标之前。 |
| 入口与房间 | 按当前村庄／页面建立挑战身份，创建页使用挑战介绍图，准备房左上角关卡名、中间地宫-01／阶段-01及对应BOSS名。 |
| 结算与返城 | 结果页提供同关重试和回城；胜败对白在恢复来源城镇后显示一次，来源位置绑定本人UID与可走坐标。 |
| 状态记录 | 四位独立通关掩码与成功收据在同一事务提交，校验角色、会话、战斗周期和结算轮次。 |
| 资源事务 | 35项场景／UI／立绘与1,154项战斗资源联合校验（单位：资源文件项），支持父资源叠加、旧标记升级、幂等应用与精确恢复。 |

## 验证范围

自动检查覆盖窗口存活、按下沿、分页关闭、来源资格、返城结果时序、立绘加载／更新／释放、最终绘制顺序、房间标题及BOSS文字、结果动作、场景排序、名牌像素、资源事务及启动器配方一致性。

准备房检查包含64种身份在名称和BOSS两个位点的文本、坐标、颜色、栈、寄存器、标志及共享记录约束（单位：身份编号×文本位点）；结果控件覆盖256组输入／绘制组合（单位：输入事件×绘制状态）。资源事务逐项校验35项文件（单位：资源文件项）、父包身份、升级标记、备份及恢复。场景排序检查覆盖四村和动画帧，名牌检查覆盖字面、描边、透明度及英文像素。

当前结论层级为客户端指令、资源一致性、适配器构造及数据库事务；完整客户端游玩状态为`runtime_acceptance=false`。实机验收范围包括四村触发、对白及立绘、前后遮挡、创建与准备房显示、加载、战斗、结算、重试和可行走返城。

本节计数的统计单位如上（身份×位点、输入×绘制状态、资源文件项）；受测产物身份以活动发布清单登记为准，未单独登记统计日期，不作为当前验收结果，归属见[验证记录的版本边界](层级与版本归属.md#kb-09-001-1)。
